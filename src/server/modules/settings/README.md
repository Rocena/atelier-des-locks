# Module `settings` (admin)

- **Rôle** : réglages de la propriétaire : réservation (délais, annulation, politique), horaires, congés et fermetures, coordonnées.
- **Horaires** : appliqués à chaque praticienne active ; un enregistrement vide est refusé (il fermerait tout).
- **Congés** : les rendez-vous déjà posés ne sont jamais annulés automatiquement ; un avertissement indique leur nombre.
- **Lecture seule** : fournisseur de réservation, lien Fresha, lien avis Google, envoi des messages (environnement du serveur).
- **Pur** : `schemas.js` (grille d'horaires, fermetures, coordonnées).
